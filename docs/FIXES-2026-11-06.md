## Known gaps not addressed
- Dark mode (static palette), push notifications, report export (PDF/Excel), per-role mobile dashboards not exercised on a device.
- 7 remaining npm advisories sit in the Expo toolchain (`expo-router`/`query-string` etc.) and need an Expo SDK major upgrade.
- Individual tokens are not revocable on logout (they expire in 8h); deactivation and password change do revoke.
- Drizzle `meta/*_snapshot.json` was not regenerated for 0002; run `drizzle-kit generate` carefully before the next schema change.
- Auto mode sends sequentially inside the request; very large classes may be slow (use manual mode or add a queue).
